ENDPOINTS CREATED:
==================

PUBLIC (No Auth Required):
- POST /api/licensing/activate
  * Activate license on machine
  * Parameters: license_key, machine_id, institution_id (optional)
  * Response: status, mode, planTier, expiry, daysRemaining

PROTECTED (Auth Required):
- GET /api/licensing/check
  * Check current license status
  * Response: mode, status, planTier, expiry, daysRemaining

- POST /api/licensing/check-in
  * Periodic validation and sync
  * Parameters: machine_id
  * Response: valid, mode, planTier, expiry, checkedInAt

- GET /api/demo-mode/status
  * Check demo mode status
  * Response: isDemo, hasLicense, mode, planTier, expiry

- POST /api/demo-mode/setup
  * Initialize demo mode for institution
  * Requires: institution_admin
  * Response: message, mode, planTier, maxStudents, expiryDate

ADMIN ONLY (Platform Admin):
- POST /api/licensing/generate-key
  * Generate test license keys
  * Parameters: institution_id, plan_tier, mode, expiry_days
  * Response: licenseKey, mode, planTier, expiryDate


MIDDLEWARE FUNCTIONS:
====================

1. checkDemoMode(req, res, next)
   - Verify license status
   - Reject if expired
   - Attach license info to request

2. addDemoWatermark(req, res, next)
   - Add _demo_watermark: true to responses
   - Add _demo_expiry to responses
   - Works with JSON responses only

3. blockDemoExports(req, res, next)
   - Block /export, /download, /report endpoints
   - Only in demo mode
   - Returns 403 error

4. capDemoStudentCount(req, res, next)
   - Cap student count at 50
   - Only on /api/dashboard/stats GET
   - Marks response with _capped_demo: true


DATABASE TABLES:
================

licenses (26 rows schema)
- id: TEXT PRIMARY KEY
- institution_id: TEXT NOT NULL (FK → institutions)
- license_key: TEXT UNIQUE NOT NULL
- mode: TEXT ('demo' | 'production')
- plan_tier: TEXT ('free' | 'basic' | 'standard' | 'premium' | 'enterprise')
- expiry_date: TEXT NOT NULL
- machine_fingerprint: TEXT (optional)
- status: TEXT ('active' | 'inactive' | 'revoked' | 'expired')
- activated_at: TEXT
- created_at: TEXT DEFAULT (datetime('now'))
- updated_at: TEXT DEFAULT (datetime('now'))

license_activations (23 rows schema)
- id: TEXT PRIMARY KEY
- institution_id: TEXT NOT NULL (FK → institutions)
- license_id: TEXT NOT NULL (FK → licenses CASCADE)
- machine_id: TEXT NOT NULL
- activated_at: TEXT NOT NULL
- last_check_in: TEXT
- ip_address: TEXT
- created_at: TEXT DEFAULT (datetime('now'))
- updated_at: TEXT DEFAULT (datetime('now'))
- UNIQUE(license_id, machine_id)

demo_mode_settings (14 rows schema)
- id: TEXT PRIMARY KEY
- institution_id: TEXT UNIQUE NOT NULL (FK → institutions CASCADE)
- max_students: INTEGER DEFAULT 50
- expiry_date: TEXT NOT NULL
- created_at: TEXT DEFAULT (datetime('now'))
- updated_at: TEXT DEFAULT (datetime('now'))

SECURITY FEATURES:
==================

RSA Cryptography:
- 2048-bit RSA key pair embedded
- Private key: Server-side only
- Public key: Embedded in app for offline validation
- License keys: Digitally signed and tamper-evident
- Signature algorithm: SHA256 with RSA

Data Protection:
- Machine fingerprinting: SHA256 hash
- IP address logging: For audit trail
- Status tracking: Prevents revoked license use
- Prepared statements: Safe from SQL injection

Authentication:
- JWT token verification (existing)
- License validation in auth middleware
- Expires check on every request
- User object enriched with license info
